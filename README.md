### _**LoongArch64**_ Plugin for [Binary Ninja](https://binary.ninja/) that work's on Linux

For new **features** ore **bugs** open a [issue](https://github.com/noah0x1/LoongArch64-Binary-Ninja-Binja-Plug-in/issues).

### Random questions no one asked me:

1. On what OS can i use it? 
> It uses Asm for Linux, so only compatible with Linux!!!

2. Will there be a Version for Windows ore MacOS? 
> Could be i release it for Windows/MacOS to. (when some one wants to help me it **could be** soon here.)

3. Will it be updated and maintained, ore is it just one version and that's it?
> NO! I wanted to do a Architecture plugin that i can maintain to also learn more C and to train my Asm skills.

4. Why LoongArch64 and not something else?
> Because Binary Ninja (Binja) doesn't have any Loongarch64 and it's used a lot.

5. Would you like that some one help's you maintaining/updating the plugin with you?
> Sure would be a big help (im still in school yes normal school not a university)
